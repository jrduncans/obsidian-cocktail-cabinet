# Contributing

Cocktail Cabinet is in beta, and feedback is the most useful contribution right now.

## Report a bug

Open an [issue](https://github.com/jrduncans/obsidian-cocktail-cabinet/issues). Include:

- What you did, what you expected, and what happened instead.
- Your Obsidian version, and whether it was on desktop or mobile (which device).
- The plugin version (**Settings → Community plugins**).
- Any errors from the developer console, if you can open it (**View → Toggle developer tools** on desktop).

Leave out personal details from your vault; a made-up note that shows the problem is enough.

## Ask a question or suggest an idea

Use [Discussions](https://github.com/jrduncans/obsidian-cocktail-cabinet/discussions) for questions, ideas, and how you use the plugin. An idea that turns into planned work gets an issue.

## Pull requests

Pull requests aren't accepted for now: the design is still changing quickly. If you'd like to fix something, open an issue first to talk it over.
